# DevStack - Explore Technologies

A modern web application to explore software technologies and build your custom tech stack.

## 🚀 Live Demo
[https://sabbir84552-web.github.io/Dev-stack/]

## ✨ Key Features
- **Dynamic Data Fetching:** Fetches technology data dynamically from JSON file.
- **Interactive Stack Builder:** Add or remove technologies from your personal stack.
- **Toast Notifications:** Instant toast feedback for adding, duplicate check, and removing items.
- **Responsive Layout:** Clean UI built with Tailwind CSS.

## 🛠️ Technologies Used
- React.js
- Tailwind CSS
- Vite
- React Toastify
